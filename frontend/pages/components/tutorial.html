Password Analysis Results Tutorial

Learn how to understand your password analysis results, explore the available sections, and use the system's features.

1. Result Summary

The Result Summary provides an overview of your password analysis. It displays the identified vulnerability, risk level, and a brief explanation of the results.

2. Password Decision Path

The Password Decision Path explains how the classification model arrives at its result. Open the detailed decision tree to explore the path followed by the model and select individual nodes to view more information.

3. Recommendations

Recommendations provide practical suggestions based on the detected password vulnerabilities. Follow these suggestions to address potential weaknesses and improve your password practices.

4. Password Characteristics

Password Characteristics displays the 14 features extracted from your password and used by the classification model. These include password length, character types, patterns, repetition, and other characteristics that help explain the classification.

5. Password Comparison

Password Comparison lets you examine two password analysis results side by side. Review their identified vulnerabilities, risk levels, and characteristics to understand which password has more favorable results based on the system's analysis.

6. Reset

Reset ends the current analysis session, clears the displayed results, and returns you to the Initial Test page so you can start a new analysis.

7. Compare Password

Select Compare Password to analyze another password while keeping your previous analysis available. The system then presents the results for comparison so you can examine their differences.

8. Tutorial

Select Tutorial whenever you need to review the available sections, understand the analysis results, or learn how to use the system's features.
