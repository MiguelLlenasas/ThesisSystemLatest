Language Limitation

The system detects password-related words and patterns based on English and Tagalog dictionaries. Passwords containing words or patterns outside these supported languages may not be fully identified or classified accurately.

About System

Password Vulnerability Assessment

This system evaluates user-generated passwords and identifies possible vulnerabilities against common password cracking strategies.

Instead of only providing a password strength score, the system analyzes password characteristics and determines the possible attack method that may affect the password.

The original password is not stored. After feature extraction, the password is removed and only the generated representation is processed.
